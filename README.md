## Overview 
This investigative assignment presents a `3349` word comparative analysis of two highly destructive, and infamous, Windows PE malware strains: **WannaCry**, and, **NotPetya**. The core objective of this report was to critically assess, and compare the specimens against each other; in areas such as: their methodologies and techniques, attack patterns, and Impact on operations.

By evaluating both specimens through techniques such as **Reverse Engineering**, and **Static Analysis**, comparisons of their underlying mechanisms were able to be drawn; with detailed mitigation and prevention techniques suggested throughout. 

## Relevant Skills  
- Static Malware Analysis through the likes of **decompilation** and analyzing PE headers.
- Binary Blob handling, including finding, extracting, and decrypting embedded payloads.
- Uncovering advanced covert techniques, real anti-analysis techniques, and how real malware evades detection.
- Proper handling of malicious binaries and the usage of secure sandbox environments.
